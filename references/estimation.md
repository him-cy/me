# 大样本量估算

## 问题

已知：需求量 `D`（最终要保留的合格图数）、小样本量 `n`、样本合格数 `q`。
求：应爬取的总数 `N`，使最终合格数 ≥ D（高置信）。

## 公式

点估计合格率：`p̂ = q / n`

用 **Wilson 95% 置信下界** 兜底（避免点估计乐观导致爬少）：
```
z = 1.96
denom = 1 + z²/n
center = (p̂ + z²/(2n)) / denom
margin = z * sqrt( p̂(1-p̂)/n + z²/(4n²) ) / denom
p_lower = max(0, center - margin)
```

大样本量：
```
N = ceil( D / p_lower × (1 + FAIL_BUF) )
```
- `FAIL_BUF = 0.15`（下载失败 + 内容重复 + 边角不合格缓冲）
- 若 `q == 0`：p_lower = 0，无法估算 → 警告换关键词/站点，不输出 N。
- 设上限 `N_CAP`（如 2000）防失控。

## 为什么用下界不用点估计

点估计 `D/p̂` 在无偏意义下"刚好够"，但小样本波动大：
- 样本 n=30, q=20 → p̂=0.667，但 95% 下界可能只有 0.49
- 用 0.49 算 N 比用 0.667 多爬 ~36%，确保大概率达标
- 代价是多爬一些，但比"爬完不够再补"成本低（补爬常遇限流/重复）

## 示例

需求 D=100，样本 n=50，合格 q=35：
- p̂ = 0.70
- p_lower ≈ 0.56（Wilson 95%）
- N = ceil(100 / 0.56 × 1.15) = ceil(205.4) = 206
- 即爬 ~206 张，预期合格 ~144，留缓冲后保留 100。

若样本 q=10（合格率仅 20%）：
- p_lower ≈ 0.10
- N = ceil(100/0.10×1.15) = 1150 → 说明该站/词质量差，建议换源或放宽标准。
